Sistema de Registro
Criminal Nacional

Plataforma de tres niveles para la digitalización del registro criminal nacional, operada exclusivamente sobre intranet nacional segura. Elimina la brecha de información inter-provincial que permite a delincuentes evadir órdenes de arresto cruzando fronteras provinciales.

Código fuente
Repositorios GitHub
Cuatro repositorios independientes — uno por tipo de nodo. Cada uno se despliega en su hardware correspondiente con un único script de instalación. El código es idéntico en base; la diferencia está en la configuración .env por máquina.
👮
Nivel 1 — Estación Policial
srcn-comisaria
Nodo local instalado en cada comisaría o puesto policial. Opera con SQLite sin servidor de base de datos. Gestiona booking de detenidos, consulta de antecedentes, emisión de warrants y sincronización automática con el nodo provincial cada 30 segundos. Funciona completamente offline — conectividad solo para sync.
Flask 3SQLite Raspberry Pi 4Jinja2 APScheduler
Angeal13/srcn-comisaria
🏛️
Nivel 2 — Nodo Provincial
srcn-nodo-provincial
Un servidor por provincia (7 en total). Agrega datos de todas las comisarías de su zona, resuelve consultas de warrants intra-provinciales en menos de 1 segundo, escala al servidor central para consultas inter-provinciales, y retransmite alertas de prófugos a todas las comisarías locales.
Flask 3MySQL 8 Mini-PC x86ThreadPoolExecutor mTLS
Angeal13/srcn-nodo-provincial
🏛️
Nivel 3 — Servidor Central
srcn-ministerio
Servidor único nacional en Malabo (Ministerio del Interior). Mantiene el índice nacional de sujetos y warrants. Resuelve consultas inter-provinciales localizando el nodo correcto y devolviendo el expediente completo en menos de 8 segundos. Propaga alertas a las 7 provincias en paralelo.
Flask 3MySQL 8 Servidor RackÍndice Nacional Dashboard Ministerio
Angeal13/srcn-ministerio
🏝️
Nivel 2 — Caso Especial
srcn-annobon
Nodo adaptado para la isla de Annobón con conectividad satelital limitada. Mismo código base que el nodo provincial pero configurado para sincronización semanal o manual. Opera completamente autónomo cuando el enlace satelital no está disponible. Opciones de sync: semanal, manual o satelital.
Flask 3MySQL 8 Sync SemanalSatelital Offline-first
Angeal13/srcn-annobon

Flujo de Tres Niveles

Stack tecnológico
Tecnología Utilizada
Todo código abierto. Sin licencias comerciales. Diseñado para hardware de bajo costo disponible localmente.
🐍
Flask 3 + Gunicorn
Backend Python. App factory pattern, blueprints por dominio, Jinja2 templates.
🗄️
SQLite / MySQL 8
SQLite en comisarías (sin servidor). MySQL en nodos provinciales y central.
🔀
Nginx + mTLS
Proxy inverso. Comunicación inter-provincial cifrada con certificados por provincia.
⚙️
APScheduler
Sync automático periódico. Fallback nocturno si el push en tiempo real falla.
🖥️
Raspberry Pi 4 / x86
Pi 4 en comisarías. Mini-PC en nodos provinciales. Servidor rack en el central.
📡
Ubiquiti airMAX / Fibra
Backbone intranet. VLAN por sistema. Sin exposición a internet público.
